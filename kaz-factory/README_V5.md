# KAZ V5 Cinematic — discovery edition

Generates **6 scene** vertical 540x960 videos from reusable, fact-reviewed scripts in `v5_topics.json`, with Wikimedia Commons photographs (license metadata included), Vietnamese Edge TTS, moving shots, crossfades, ASS subtitles with highlighted words and cinematic thumbnails. Videos are **review-required**. Images and voice need internet. Source image licenses vary: inspect `attribution.json` and comply with attribution requirements before publishing. No copyrighted music is bundled.

Run: `python kaz-factory/v5.py --count 1`. Outputs `output-v5/<date>/video_001/`. Requires FFmpeg with libass and Python packages. If no properly licensed media is available, it **fails** rather than silently replacing real photos with generic graphics. If online TTS fails, it fails rather than producing a silent video.

The word highlighting is approximate and timed using narration sentence lengths, **not** phoneme-perfect karaoke. 6 scene photos are fetched from Wikimedia Commons; they are **not generated by AI**. Content scripts are human-authored templates; there is no autonomous AI research or publication. 50 videos/day is not guaranteed on free GitHub runners. Only two prepared topics are included; repeated content should not be bulk published.

Workflow `.github/workflows/kaz-v5.yml` supports manual run and a scheduled daily smoke-test draft after merging into default branch. Output artifacts expire after 7 days.
